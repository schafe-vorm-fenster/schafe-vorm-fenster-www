# SSD

## Purpose

The System Specification Document for the website relaunch: purpose, scope,
context, goals, stakeholders, and open issues — the top of the STRICT chain
(goal → need → requirement → tactical specification → verification).

Goals and stakeholders are **references into `go-to-market-os`**, which is
the single source of truth (ADR-001). This document deliberately contains
no restated goal texts and no audience descriptions.
