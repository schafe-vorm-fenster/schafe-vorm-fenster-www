## Decision

Media-echo entries carry `usage_rights` with the same values as proof —
`cleared` / `unverified`. No separate vocabulary for links, quotes and
reproductions.

## Consequences

- All 32 verified entries need the field added and each needs a real
  judgement; a missing field stays no assertion, so the archive and every
  proof stream draw only on entries someone has cleared.
- The archive will be sparse at first and fills as clearances are given.
  The honest empty state carries it (TS-028).
- Resolves Q-045 as a decision; the clearing work itself is the hub's,
  alongside the five unverified testimonials of Q-014.
