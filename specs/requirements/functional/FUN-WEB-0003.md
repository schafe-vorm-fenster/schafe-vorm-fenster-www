# FUN-WEB-0003

Each page shall present exactly one primary conversion, above the fold, visually unrivalled — exactly one element carrying the primary marker, one unmarked repeat in the closing block, and every other action at secondary treatment: module CTAs, tier CTAs, the context band and every row of the contact section. A hero may carry a second, adjacent secondary action where the page brief declares a goal of equal weight (order versus consult).
