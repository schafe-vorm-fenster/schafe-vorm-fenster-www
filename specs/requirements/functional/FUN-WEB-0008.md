# FUN-WEB-0008

Each job shall be introduced through a concrete scene: an opener that is a statement of what works, exactly one mechanism, a block that stands without the one above it, never a feature list. Generic claims ("einfach", "digital") are not copy. How that copy is written — register, structure, concreteness, economy, headings, length budgets, truth — is SRC-0017; which mechanism enforces which rule is SRC-0018.
