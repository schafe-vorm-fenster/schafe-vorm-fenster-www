# FUN-WEB-0138

For every job, the website SHALL introduce it through a concrete scene.

## Notes

The scene's shape, from SRC-0001 §1a: an opener that is a statement of what works, exactly one mechanism, a block that stands without the one above it, never a feature list. How the copy is written — register, structure, concreteness, economy, headings, length budgets, truth — is SRC-0017; which mechanism enforces which rule is SRC-0018.
