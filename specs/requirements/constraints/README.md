# Constraints

## Purpose

Fixed decisions bounding the solution space: technology, brand, and scope
boundaries. A constraint is not argued per page — it holds everywhere.

Each constraint is **one document**, named for its identifier
(`CON-WEB-0001.md`). This file is the index: it groups them by area,
carries the area notes that belong to no single constraint, and records
each one's source and evidence-sufficiency level. The statement itself
lives in the constraint's own file and nowhere else.
