# AGENTS

This repository is the home of the official Schafe vorm Fenster website.

## Project Context

- The previous site implementation was intentionally removed from the repository root.
- Legacy website material was preserved under `legacy-content/`.
- A new website stack will be introduced later.
- Until then, treat the repository as a reset project with archived source material.

## Read First

- `README.md` for the repository purpose and current state
- `CONTRIBUTING.md` for the current development workflow
- `legacy-content/README.md` for the archived website content layout
- `.github/copilot-instructions.md` for mirrored agent bootstrap instructions

## Working Rules

1. Start with the current repository state, not the assumptions of the former Next.js app.
2. Do not move legacy files back into the repository root unless explicitly asked.
3. Preserve `legacy-content/` as the reference archive for copy, assets, and import logic.
4. Prefer small, well-documented changes while the new stack is not defined yet.
5. When adding a new technical foundation, update `README.md` and `CONTRIBUTING.md` in the same change.

## Typical Tasks

- review or extract legacy content
- prepare new information architecture or content models
- add baseline repository structure for the rebuild
- document development conventions as the new stack takes shape
