# Product Content

This folder contains product families, offers, pricing, and packaging content.

Use it as the source for pricing tables, offer pages, and sales-oriented sections.

## Modeling Notes

- A file can describe a standalone product or a product family.
- A file can also describe one tariff, package, or variant within a larger product family.
- Shared product logic should be documented once in the product-family file instead of repeated across every tariff.

## Current Product Grouping

- `portalize.md` is the umbrella product for website and portal integrations.
- `portalize-webseiten-widget.md`, `portalize-netzwerkkalender.md`, and `portalize-regionale-einbindung.md` describe Portalize variants with different scopes and tariffs.
- `dorfkalender.md` remains the free base offer.
- `lokale-werbung.md` remains a separate commercial offer.
